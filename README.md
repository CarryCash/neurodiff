## 🚀 Quick Start

```bash
# 1. Initialize the ChromaDB index for duplication checks
neurodiff index .

# 2. Analyze the difference between two branches
neurodiff analyze origin/main HEAD --llm

# 3. Generate a beautiful HTML report
neurodiff analyze origin/main HEAD --format html > report.html

# 4. Generate automated tests and documentation
neurodiff shadow --mode all

# 5. Review algorithm performance automatically
neurodiff perf . --write-benchmarks
```

## 🧠 Engines

NeuroDiff uses a sequential pipeline of 7 specialized engines:
1. **AST Engine:** Detects what actually changed (functions, classes) ignoring whitespace.
2. **Security Engine:** Semgrep-powered deterministic vulnerability checks.
3. **Duplication Engine:** ChromaDB-powered vector search to prevent reinventing the wheel.
4. **Architecture Engine:** Verifies if changes violate predefined `rules.yml` guidelines.
5. **LLM Verification Engine:** Detects AI hallucinations and ensures code intent matches.
6. **Cognitive Load Engine:** Measures code readability and complexity.
7. **Algorithm Performance Engine:** Rewrites O(n²) algorithms into O(n) or O(1) structures.

## ⚙️ CI/CD Integration

NeuroDiff seamlessly integrates into your existing pipelines to block bad PRs.

### GitHub Actions
```yaml
name: NeuroDiff Review
on: [pull_request]
jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - run: pip install neurodiff
      - run: neurodiff analyze origin/${{ github.base_ref }} HEAD --llm --inline-comments --fail-on-critical-logic
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          GOOGLE_API_KEY: ${{ secrets.GOOGLE_API_KEY }}
```

### GitLab CI
```yaml
neurodiff:
  image: python:3.11
  script:
    - pip install neurodiff
    - neurodiff analyze $CI_MERGE_REQUEST_DIFF_BASE_SHA $CI_COMMIT_SHA --llm --inline-comments
```

### Bitbucket Pipelines
```yaml
pipelines:
  pull-requests:
    '**':
      - step:
          script:
            - pip install neurodiff
            - neurodiff analyze origin/main HEAD --llm --inline-comments
```
